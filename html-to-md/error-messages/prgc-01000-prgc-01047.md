PRGC-01000: Internal error \[# {0} #\].

Cause: An internal error occurred.

Action: Contact Oracle Support Services.

PRGC-01001: OCI API "{0}" called by OCI user "{1}" failed for resource with OCID "{2}".

Cause: The inidicated Oracle Cloud Infrastructure (OCI) API call made by the specified OCI user for the resource with the indicated Oracle Cloud Identifier (OCID) returned an unexpected response.

Action: Review the accompanying error messages. Ensure that the indicated resource OCID is valid, the specified OCI user has appropriate privileges to access the OCI resource, and then retry the operation.

PRGC-01002: The body of the response for OCI API "{0}" called by OCI user "{1}" for resource with OCID "{2}" does not contain property "{3}".

Cause: The body of the response for the inidicated Oracle Cloud Infrastructure (OCI) API call made by the specified OCI user for the resource with the indicated Oracle Cloud Identifier (OCID) did not include the indicated property.

Action: Ensure that the indicated resource OCID is valid, the specified OCI user has appropriate privileges to access the OCI resource, and then retry the operation.

PRGC-01003: failed to unzip client credentials for Autonomous Database with OCID "{0}"

Cause: An attempt to unzip the client credentials downloaded for the Autonomous Database with the specified Oracle Cloud Identifier (OCID) failed.

Action: Review the accompanying error messages. Ensure that the specified OCID is valid, the Oracle Cloud Infrastructure API GenerateAutonomousDatabaseWallet returns a valid response for the specified OCID, and then retry the operation.

PRGC-01004: failed to parse OCI SDK configuration file "{0}"

Cause: The specified Oracle Cloud Infrastructure (OCI) Software Development Kit (SDK) configuration file could not be parsed.

Action: Review the Oracle Cloud Infrastructure documentation for information about SDK and CLI configuration files, ensure that the specified SDK configuration file exists and contains all required entries, and then retry the operation.

PRGC-01005: OCI SDK configuration file "{0}" is missing required entry "{1}".

Cause: The specified Oracle Cloud Infrastructure (OCI) Software Development Kit (SDK) configuration file was missing the indicated entry.

Action: Review the Oracle Cloud Infrastructure documentation for information about SDK and CLI configuration files, ensure that the specified SDK configuration file contains all required entries, and then retry the operation.

PRGC-01006: failed to upload object to OCI Object Store bucket "{0}" as OCI user "{1}"

Cause: An attempt to upload an object to the specified Oracle Cloud Infrastructure (OCI) Object Store bucket as the specified OCI user failed.

Action: Review the accompanying error messages, resolve the issues, and then retry the operation.

PRGC-01007: failed to delete object "{0}" in OCI Object Store bucket "{1}" as OCI user "{2}"

Cause: An attempt to delete the indicated object in the specified Oracle Cloud Infrastructure (OCI) Object Store bucket as the specified OCI user failed.

Action: Review the accompanying error messages, resolve the issues, and then retry the operation.

PRGC-01008: Private key generated with a passphrase is not supported.

Cause: The specified Oracle Cloud Infrastructure (OCI) Software Development Kit (SDK) configuration file contained an encrypted private key.

Action: Generate the private key without a passphrase, and then retry the operation.

PRGC-01039: Zero Downtime Migration Cloud Service (ZDMCS) property file {0} does not exist

Cause: An attempt to locate the specified ZDMCS property file failed.

Action: Ensure that the path and name of the ZDMCS property file are entered correctly and that the file exists and is readable.

PRGC-01040: failed to initialize metrics framework "{0}"

Cause: An attempt to initialize the metrics framework to push Telemetry System metrics failed.

Action: Ensure that the Telemetry System configuration parameters specified are valid and correct and then retry the operation.

PRGC-01041: no public domain name for "{0}" available

Cause: An attempt to retrieve a public domain based on region failed because there is no public domain available.

Action: Ensure that the public domain exists for the region provided.

PRGC-01042: invalid T2\_JOB\_INTERVAL parameter "{0}"

Cause: An invalid T2\_JOB\_INTERVAL parameter was specified.

Action: Ensure that a valid T2\_JOB\_INTERVAL is specified in the Zero Downtime Migration Cloud Service property file.

PRGC-01043: Private endpoint "{0}" is not available.
