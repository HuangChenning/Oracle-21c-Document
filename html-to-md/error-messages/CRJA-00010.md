CRJA-00010: Resource "{0}" timeout while performing "{1}" action

Cause: The specified resource was timed out while performing specified action. This may not indicate a problem if it occurred while starting or stopping the CRS stack.

Action: Check if the resource is online after a while. Otherwise, contact Oracle Support Services.

CRJA-00015: The cluvfy process is still running. Waiting for clean action on "ora.cvu" resource.

Cause: This is a progress message while stopping the Configuration Verification Utility (CVU) resource. The CVU agent found that the cluvfy process was still running.

Action: None
