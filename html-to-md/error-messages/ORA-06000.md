ORA-04101: unsupported language string

Cause: An attempt was made to use an unsupported language.

Action: Use a supported language when creating modules or calling the function DBMS\_MLE.eval.

ORA-04102: module string already exists

Cause: An attempt was made to create a module whose name conflicted with an existing module.

Action: Remove the existing module before deploying the new one or replace the existing module using CREATE OR REPLACE.

ORA-04103: module string does not exist

Cause: An attempt was made to use a non-existent module.

Action: Create the named module or use an existing module.

ORA-04104: environment string already exists

Cause: An attempt was made to create an environment whose name conflicted with an existing environment.

Action: Remove the environment before recreating it or replace the existing environment using CREATE or REPLACE.

ORA-04105: environment string does not exist

Cause: An attempt was made to perform an action using an environment that did not exist.

Action: Create the named environment or use an existing environment.

ORA-04106: module string modified since context creation

Cause: An attempt was made to use a function of a module that had been modified since the execution context was created.

Action: Re-run the function. Rerunning the function creates and uses a new execution context.

ORA-04107: environment or its mapped modules modified since context creation

Cause: An attempt was made to use an environment that had been modified since the execution context was created.

Action: Create a new dynamic context, or rerun the function. Rerunning the function creates and uses a new execution context.

ORA-04108: Effective userid, roles, or container changed since context creation.

Cause: An attempt was made to access an execution context with a different userid or roles or from a different container.

Action: Use the original userid, roles, and container to access the execution context.

ORA-04109: Import name string already exists.

Cause: An attempt was made to add an import to an environment whose name conflicted with an existing import.

Action: Use a different import name, alter the existing import via ALTER IMPORT, or drop the existing import before adding the new one.

ORA-04110: Import name string does not exist.

Cause: An attempt was made to alter or drop a non-existent import in an environment.

Action: Use an import name that exists.

ORA-04111: duplicate import name string

Cause: An import name was used more than once for this environment.

Action: Do not use the same import names multiple times for one environment.

ORA-04112: invalid or missing version string

Cause: The version string specified for the Multilingual Engine (MLE) module was invalid or missing.

Action: Specify a valid version string for the MLE module.

ORA-04113: invalid or missing language option string

Cause: The language option string specified for the Multilingual Engine (MLE) environment was invalid or missing.

Action: Specify a valid language option string for the MLE environment.

ORA-04114: invalid or missing import name

Cause: The provided import name was invalid or missing.

Action: Specify a valid import name.

ORA-04115: invalid or missing mle module name

Cause: The provided mle module name was invalid or missing.

Action: Specify a valid mle module name.

ORA-04116: invalid or missing mle env name

Cause: The provided mle env name was invalid or missing.

Action: Specify a valid mle env name.

ORA-04117: invalid or missing metadata

Cause: The provided metadata was invalid or missing.

Action: Specify valid metadata for the MLE module.

ORA-04118: module import string is a synonym for a remote object

Cause: An attempt was made to specify a synonym for a remote object as an import in an environment. Remote objects are not allowed.

Action: Change the synonym to a local module object.

ORA-04119: MLE module string has errors

Cause: The Multilingual Engine (MLE) module had errors.

Action: Resolve any compilation errors on the MLE module.

ORA-04120: Insufficient privileges to use module string

Cause: An attempt was made to import a module in an environment, or use a module on a call specification, without sufficient privileges.

Action: Get necessary privileges.

ORA-04121: only EXECUTE and DEBUG MLE privileges are valid for modules

Cause: An attempt was made to GRANT or REVOKE an invalid privilege on a module.

Action: GRANT or REVOKE only the EXECUTE and DEBUG MLE privilege on modules.

ORA-04122: only the EXECUTE privilege is valid for environments

Cause: An attempt was made to GRANT or REVOKE an invalid privilege on an environment.

Action: GRANT or REVOKE only the EXECUTE privilege on environment.

ORA-04123: Insufficient privileges to use environment string

Cause: An attempt was made to use an environment without sufficient privileges.

Action: Get necessary privileges.

ORA-04124: Authorization error for MLE module referenced in MLE environment

Cause: The Multilingual Engine (MLE) environment was not authorized to include the listed MLE module as an import definition.

Action: Get necessary privileges on all referenced modules.

ORA-04158: Property string does not exist.

ORA-04163: invalid type mapping from string to string

ORA-04164: Missing DEBUG MLE privilege on string

Action: Grant the DEBUG MLE privilege on the module or disable debugpoints for the module.

ORA-04165: invalid debug specification - string

Action: Provide a valid debug specification.

ORA-04166: invalid debug output

ORA-04251: internal error string

Cause: An internal error occurred while evaluating a code snippet or a function.

Action: Contact your customer support representative.

ORA-04252: resource limit reached string

ORA-04253: system error string

ORA-04254: Multilingual Engine (MLE) does not support Multi Process Multi Threads (MPMT).

Cause: An attempt was made to use the Multilingual Engine (MLE) with Multi Process Multi Threads (MPMT) enabled.

Action: Disable the Multi Process Multi Threads (MPMT) before using the Multilingual Engine (MLE). Retry after MPMT is disabled.

ORA-04255: Multilingual Engine (MLE) does not support shared servers.

Cause: An attempt was made to use the Multilingual Engine (MLE) with a shared server.

Action: Use a dedicated server to use the Multilingual Engine (MLE).

ORA-04256: cannot start the Multilingual Engine (MLE), instance PGA\_AGGREGATE\_LIMIT too low

Cause: The instance PGA\_AGGREGATE\_LIMIT prevented from starting the Multilingual Engine (MLE).

Action: Increase the instance PGA\_AGGREGATE\_LIMIT.

ORA-04257: cannot start the Multilingual Engine (MLE), per-PDB PGA\_AGGREGATE\_LIMIT too low

Cause: The per-PDB PGA\_AGGREGATE\_LIMIT prevented from starting the Multilingual Engine (MLE).

Action: Increase the PDB PGA\_AGGREGATE\_LIMIT.

ORA-04258: Cannot start the Multilingual Engine (MLE) because the per-session Program Global Area (PGA) limit is too low.

Cause: Database Resource Manager enforced a limit for this session's use of private memory, referred to as the session's Program Global Area. The Resource Manager limit, session\_pga\_limit, is too low for MLE to start.

Action: Identify the session's resource consumer group and use it to identify the session\_pga\_limit. Increase the consumer group's session\_pga\_limit using Database Resource Manager API, then retry the operation.

ORA-04259: Multilingual Engine (MLE) failed to load

Cause: A severe error prevented Multilingual Engine (MLE) from loading and initializing. This might have been caused by a corrupted software installation.

Action: Please contact Oracle Support for further assistance.

ORA-04260: Multilingual Engine (MLE) does not support Database Resident Connection Pooling (DRCP).

Cause: An attempt was made to use the Multilingual Engine (MLE) with Database Resident Connection Pooling (DRCP) enabled.

Action: Turn off Database Resident Connection Pooling (DRCP) before using the Multilingual Engine (MLE).

ORA-04261: Multilingual Engine (MLE) is not available on this platform

Cause: An attempt was made to use the Multilingual Engine (MLE) on a platform where MLE was not available.

Action: Use the Multilingual Engine (MLE) on a platform where MLE is available.

ORA-04262: the compilation thread for Multilingual Engine (MLE) terminated

Cause: The Multilingual Engine (MLE) was terminated.

Action: No action required.

ORA-04263: the compilation thread for Multilingual Engine (MLE) crashed

Cause: An error happened in the compilation thread for Multilingual Engine (MLE).

Action: Disable Multilingual Engine (MLE) background compilation.

ORA-04270: timezone region not available in the Multilingual Engine (MLE)

Cause: The session timezone is not available in the Multilingual Engine (MLE).

Action: Choose another session timezone.

ORA-05000: cannot create foreign key constraints on columns referencing a sharded table

Cause: An attempt was made to create a foreign key constraint in a duplicate table on a column referencing a sharded table.

Action: Remove the foreign key constraint referencing a column in the sharded table.

ORA-05001: source and target shardspaces have different number of chunks

Cause: ALTER TABLE SPLIT PARTITIONSET operation did not have an equal number of chunks in source and target shardspaces.

Action: Make number of chunks equal on the source and target shardspaces by using the SPLIT CHUNK command and then retry.

ORA-05002: names assigned to resulting partitionsets must be distinct

Cause: Names of the partitionsets resulting from splitting the existing partitionset were not distinct.

Action: Rename the resulting partitionsets to ensure that their names are distinct and different from those of any other existing partitionset.

ORA-05003: tablespaces can be specified for only one of the resulting partitionsets

Cause: Tablespaces for all resulting partitionsets were either specified or not specified at all.

Action: Specify the tablespace for only one resulting partitionset.

ORA-05004: partitionset already exists in target shardspace for the same FAMILY\_ID.

Cause: The partitionset already existed in the target shardspace of the SPLIT PARTITIONSET operation.

Action: The target shardspace needs to be empty for the SPLIT PARTITIONSET operation.

ORA-05005: row count mismatch between source and target during the SPLIT PARTITIONSET operation

Cause: The expected rows count on the target side did not match the source row count during the SPLIT PARTITIONSET operation.

Action: Clean up the target shardspace before retrying the SPLIT PARTITIONSET operation.

ORA-05009: Sharding key update is not supported for this table.

ORA-05010: Updating more than one sharding column at a time is not supported.

ORA-05011: cannot enable foreign key constraint

Cause: An attempt was made to enable a foreign key constraint that existed between a sharded table and a duplicated table. Such constraints can only exist in a disabled state because they cannot be enforced on the shard or the catalog.

Action: This operation is not allowed.

ORA-05012: cannot operate on multiple constraints for duplicated table

Action: Operate on only one constraint at a time.

ORA-05013: cannot create unique index on primary key columns of a duplicated table

Action: Enable the primary key constraint to create this index automatically.

ORA-05014: invalid specification of a clause in CREATE TABLESPACE statement in sharding environment

Cause: An unsupported clause was specified in the CREATE TABLESPACE statement in a sharding environment.

Action: Drop the unsupported clause and reissue the CREATE TABLESPACE statement.

ORA-05015: cannot set or alter the default tablespace of a sharded table

Action: None. A default tablespace cannot be set for sharded tables.

ORA-05016: The sharding key is not found or does not belong to the shard

Cause: A request was made to either the shard catalog with a sharding key that did not belong to any shard, or to a shard with a sharding key that did not belong to this shard.

Action: Check the sharding key value in the request.

ORA-05017: root table required for routing not found

Action: Check the presence of sharded table definitions.

ORA-05018: cannot find a matching sharded table family

Cause: There was no matching table family for the request, either because the service was not associated with any table family or no sharded table family existed.

Action: Check the table family associated with the service and the presence of sharded table definitions.

ORA-05019: the super sharding key does not belong to this shard

Action: Check the super sharding key value and the partition set mapping to the shards.

ORA-05020: inconsistent shard routing metadata with request

Action: Check the request sharding key and and super sharding key specification and sharding configurations.

ORA-05021: SHARDED clause contradicts GLOBAL or LOCAL clause

Action: Specify only one of SHARDED, LOCAL or GLOBAL clause.

ORA-05022: Locking rows for sharding key update failed.

Cause: One of steps involved in locking rows for the sharding key update failed.

Action: Check the error stack and other messages in the trace files for detailed error information.

ORA-05023: chunk id string is in the middle of chunk move operation. Retry after chunk move is done.

Cause: chunk id was in the middle of a chunk move operation.

Action: Retry after the chunk move is done.

ORA-05024: cannot update the sharding key when row movement is not enabled.

Cause: cannot update the sharding key when row movement is not enabled.

Action: Enable row movement for all tables in this table's table family.

ORA-05025: cannot update the sharding key when SNR is enabled

Cause: An attempt was made to update the sharding key when sharding native replication was enabled.

Action: Do not try to update the sharding key when SNR is enabled.

ORA-05026: cannot delete or update parent key referenced by sharded table

Cause: An attempt was made to delete or update a row from a duplicated table when a foreign key constraint existed in a sharded table referencing this duplicated table and the constraint was ENABLED.

Action: DISABLE NOVALIDATE the constraint before attempting to delete or update rows from the duplicated table. When a sharded table references a duplicated table, deleting a parent row is only allowed when the constraint is in DISABLE state. This means rows from the child sharded table are not looked up for violation. The constraint state can later be changed to ENABLE VALIDATE if there are no rows in sharded table violating the constraint and after duplicated table is refreshed on all shards.

ORA-05027: cannot use ON DELETE clause for this constraint

Cause: A foregin key constraint was being created or altered in a sharded table referencing a duplicated table with ON DELETE clause.

Action: Remove the ON DELETE clause.

ORA-05028: cannot create a sharded index on this table

Cause: Creating sharded indexes is restricted to sharded tables in certain sharding methods.

Action: Do not specify SHARDED keyword in the create index statement.

ORA-05031: PDB SGA usage has exceeded the limit

Cause: The pluggable database (PDB) was using more system global area (SGA) than the limit set by the SGA\_TARGET parameter.

Action: Increase the PDB's SGA\_TARGET (limit).

ORA-05032: operation only allowed with directory-based sharding

Cause: An attempt was made to perform an operation that is only supported with directory-based sharding.

Action: Check the definition of the sharded root table, if any. Create or re-create the table with the PARTITION BY DIRECTORY clause to enable directory-based sharding.

ORA-05033: error with SHA-256 calculation on the sharding key

Action: Check the sharding key value, ensure that all key columns match the corresponding sharding key column definition and are in the correct order.

ORA-05035: no matching partition found for string for directory insert

ORA-05036: no matching record found for specified key in the directory

ORA-05037: only the schema owner is allowed to modify the directory

ORA-05038: shard directory can only be modified on the shard catalog

ORA-05039: partition bound specified when adding this partition

Cause: Either a VALUES LESS THAN clause or a VALUES (<values\_list>) clause was specified when adding a partition to a directory partitioned table, which is not allowed.

Action: Remove the VALUES LESS THAN clause or VALUES (<values\_list>) clause from the partition being added.

ORA-05040: DEFAULT partition is not allowed in a directory partitioned table

Cause: The DEFAULT clause was specified for a partition in a directory partitioned table, which is not allowed.

Action: Remove the DEFAULT clause.

ORA-05045: invalid DIRECTORY clause specified for a non-directory-based sharded root table creation

Cause: DIRECTORY can only be specified for the creation of a directory-based sharded root table and must be followed by TABLESPACE.

Action: Remove the DIRECTORY clause if the statement is not for the creation of a directory-based sharded root table, otherwise, specify the tablespace with DIRECTORY TABLESPACE clause.

ORA-05046: cannot allocate string bytes of memory for Sharding Replication Unit string

ORA-05049: maximum number of replication units (string) reached on shard string

ORA-05050: Standby catalog does not support DDL operations.

ORA-05052: In a Sharding Replication system Barrier DDL on sharded table string.string is not allowed directly on a shard from a session that has enabled shard ddl.

Cause: In a Sharding Replication system, Barrier DDL directly issued on a shard from a session that has enabled shard ddl can lead to data or schema inconsistency and is not allowed.

Action: When running Sharding Replication issue Barrier DDL on a sharded table from the catalog connection if you want to change the table schema or truncate the table.
