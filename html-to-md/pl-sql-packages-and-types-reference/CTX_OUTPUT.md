## 9 CTX\_OUTPUT

This Oracle Text package lets you manage the index log.

Note that you must install this package in order to use it.

For a complete description of this package within the context of Oracle Text, see [`CTX_OUTPUT`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/21/arpls&id=CCREF0800) in the Oracle Text Reference.
