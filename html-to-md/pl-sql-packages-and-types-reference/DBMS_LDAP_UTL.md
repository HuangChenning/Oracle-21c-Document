## 102 DBMS\_LDAP\_UTL

The DBMS\_LDAP\_UTL package contains the Oracle Extension utility functions.

For a complete description of this package within the context of Oracle Internet Directory, see `DBMS_LDAP_UTL` in the [Application Developer's Guide for Oracle Identity Management](https://docs.oracle.com/en/middleware/idm/internet-directory/12.2.1.3/oimad/programming-oracle-identity-management.html#GUID-3209068D-D5C1-4B89-B017-B38827204B77.html).
