## 235 SDO\_CS

The `SDO_CS` package contains functions and procedures for working with coordinate systems.

You can perform explicit coordinate transformations on a single geometry or an entire layer of geometries (that is, all geometries in a specified column in a table).

For a complete description of this package within the context of Oracle Spatial, see [`SDO_CS`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/21/arpls&id=SPATL140) in the Oracle Spatial and Graph Developer's Guide.
