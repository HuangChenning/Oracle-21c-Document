## 255 SDO\_UTIL

The `SDO_UTIL` package contains the utility functions and procedures for Oracle Spatial.

For complete description of this package within the context of Oracle Spatial, see [`SDO_UTIL`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/21/arpls&id=SPATL180) in the Oracle Spatial and Graph Developer's Guide.
