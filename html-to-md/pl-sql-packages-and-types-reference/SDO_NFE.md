## 247 SDO\_NFE

The `SDO_NFE` package contains functions and procedures for performing network feature editing.

For a complete description of this package within the context of Oracle Spatial and Graph, see `SDO_NFE` in the Oracle Spatial and Graph Topology Data Model and Network Data Model Graph Developer's Guide.
