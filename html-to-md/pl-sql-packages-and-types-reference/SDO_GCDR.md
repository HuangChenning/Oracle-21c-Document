## 237 SDO\_GCDR

The `SDO_GCDR` package contains the Oracle Spatial geocoding subprograms, which let you geocode unformatted postal addresses.

For a complete description of this package within the context of Oracle Spatial, see [SDO\_GCDR](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/21/arpls&id=SPATL145) in the Oracle Spatial and Graph Developer's Guide.
