## 239 SDO\_GEOR

The `SDO_GEOR` package contains functions and procedures for the Oracle Spatial GeoRaster feature, which lets you store, index, query, analyze, and deliver raster image data and its associated spatial vector geometry data and metadata.

For complete description of this package within the context of Oracle Spatial, see [`SDO_GEOR`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/21/arpls&id=GEORS400) in the Oracle Spatial and Graph GeoRaster Developer's Guide.
