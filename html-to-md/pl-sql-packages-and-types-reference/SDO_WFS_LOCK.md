## 256 SDO\_WFS\_LOCK

The `SDO_WFS_LOCK` package contains subprograms for WFS support for registering and unregistering feature tables. Registering a feature table enables the table for WFS transaction locking; unregistering a feature table disables the table for WFS transaction locking.

For a complete description of this package within the context of Oracle Spatial, see [`SDO_WFS_LOCK`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/21/arpls&id=SPATL147) in the Oracle Spatial and Graph Developer's Guide.
