## 243 SDO\_GEOR\_UTL

The `SDO_GEOR_UTL` package contains utility functions and procedures for the Oracle Spatial GeoRaster feature, including those related to using triggers with GeoRaster data.

For complete description of this package within the context of Oracle Spatial, see [`SDO_GEOR_UTL`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/21/arpls&id=GEORS500) in the Oracle Spatial and Graph GeoRaster Developer's Guide.
