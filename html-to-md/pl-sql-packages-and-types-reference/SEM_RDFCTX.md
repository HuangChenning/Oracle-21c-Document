## 261 SEM\_RDFCTX

The `SEM_RDFCTX` package contains subprograms for managing extractor policies and semantic indexes created for documents.

For a complete description of this package within the context of Oracle Database semantic technology support, see [`SEM_RDFCTX`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/21/arpls&id=RDFRM800) in the Oracle Spatial and Graph RDF Semantic Graph Developer's Guide
