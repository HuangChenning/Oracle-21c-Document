## 244 SDO\_LRS

The `SDO_LRS` package contains functions that create, modify, query, and convert linear referencing elements.

For a complete description of this package within the context of Oracle Spatial, see [`SDO_LRS`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/21/arpls&id=SPATL150) in the Oracle Spatial and Graph Developer's Guide.
