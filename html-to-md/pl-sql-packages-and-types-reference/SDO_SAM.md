## 250 SDO\_SAM

The `SDO_SAM` package contains functions and procedures for spatial analysis and data mining.

For a complete description of this package within the context of Oracle Spatial, see [`SDO_SAM`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/21/arpls&id=SPATL190) in the Oracle Spatial and Graph Developer's Guide.
