## 3 CTX\_ADM

The `CTX_ADM` package lets you administer the Oracle Text data dictionary.

Note that you must install this package in order to use it.

For a complete description of this package within the context of Oracle Text, see [`CTX_ADM`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/21/arpls&id=CCREF0500) in the Oracle Text Reference.
