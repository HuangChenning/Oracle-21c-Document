## 259 SEM\_OLS

The `SEM_OLS` package provides an interface to the `SEM_OLS` package for providing triple-level security to RDF data, using Oracle Label Security (OLS).

For a complete description of this package, see [`SEM_OLS`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/21/arpls&id=RDFRM395) in the Oracle Spatial and Graph RDF Semantic Graph Developer's Guide.
