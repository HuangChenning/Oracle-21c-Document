## 2 Oracle Application Express Packages APEX\_APPLICATION Through APEX\_ZIP

The Oracle Application Express supplies PL/SQL packages for application developers who are building database-centric web applications using Oracle Application Express.

For a complete description of all the packages that ship with Oracle Application Express, see the [Oracle Application Express API Reference](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/21/arpls&id=AEAPI538).
