## 241 SDO\_GEOR\_AGGR

The `SDO_GEOR_AGGR` package provides an interface to the SDO\_GEOR\_AGGR package for performing aggregate operations on GeoRaster objects.

For a complete description of this package within the context of Oracle Spatial, see [`SDO_GEOR_AGGR`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/21/arpls&id=GEORS1224) in the Oracle Spatial and Graph GeoRaster Developer's Guide.
