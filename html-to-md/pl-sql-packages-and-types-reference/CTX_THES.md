## 12 CTX\_THES

This Oracle Text package lets you to manage and browse thesauri.

Note that you must install this package in order to use it.

For a complete description of this package within the context of Oracle Text, see [`CTX_THES`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/21/arpls&id=CCREF1600) in the Oracle Text Reference.
