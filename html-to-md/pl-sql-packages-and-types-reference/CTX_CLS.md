## 5 CTX\_CLS

The `CTX_CLS` package enables generation of CTXRULE rules for a set of documents.

For a complete description of this package within the context of Oracle Text, see [`CTX_CLS`](https://docs.oracle.com/pls/topic/lookup?ctx=en/database/oracle/oracle-database/21/arpls&id=CCREF1500) in the Oracle Text Reference.
