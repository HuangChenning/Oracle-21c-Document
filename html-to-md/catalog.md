# Oracle Database 21c 文档目录

路径都相对于本文件所在的 `html-to-md` 目录。检索时先选定一本书，再打开该书的 `contents.md`。

## 概念与开发

- `concepts/contents.md`：Database Concepts（F31733-09）。数据库体系结构、事务、存储、进程和数据字典。在线文档 F31733-09，本地 PDF 为 F31733-07。
- `development-guide/contents.md`：Database Development Guide（F31304-06）。应用开发中的数据库特性、数据类型和程序接口。

## 管理、参数与排错

- `administrators-guide/contents.md`：Database Administrator's Guide（F31835-17）。建库、启动关闭、表空间、用户、调度和诊断。
- `multitenant-administrators-guide/contents.md`：Multitenant Administrator's Guide（F31734-10）。CDB、PDB 的创建、克隆、插入和管理。
- `performance-tuning-guide/contents.md`：Database Performance Tuning Guide（F32091-03）。实例调优、等待事件和统计信息。
- `2-day-performance-tuning-guide/contents.md`：2 Day + Performance Tuning Guide（F32092-02）。用 Enterprise Manager 做日常性能调优。
- `sql-tuning-guide/contents.md`：SQL Tuning Guide（F31828-11）。SQL 执行计划、优化器和调优方法。
- `utilities/contents.md`：Oracle AI Database Utilities Guide（F30732-30）。Data Pump、SQL*Loader、外部表等工具。在线文档 F30732-30，本地 PDF 为 F30732-27。
- `reference/contents.md`：Database Reference（F31274-35）。初始化参数、静态数据字典视图和动态性能视图。在线文档 F31274-35，本地 PDF 为 F31274-25。
- `error-messages/contents.md`：Database Error Messages（F30283-07）。ORA-、PLS-、TNS- 等错误号的原因和处理。

## 存储

- `automatic-storage-management-administrators-guide/contents.md`：Automatic Storage Management Administrator's Guide（F30296-05）。ASM 磁盘组和文件系统管理。
- `advanced-cluster-file-system-administrators-guide/contents.md`：Advanced Cluster File System Administrator's Guide（F30297-04）。Oracle ACFS 集群文件系统的管理。

## 高可用

- `high-availability-overview-and-best-practices/contents.md`：High Availability Overview and Best Practices（F46646-49）。高可用架构和 MAA 配置实践。在线文档 F46646-49，本地 PDF 为 F46646-31。
- `data-guard-concepts-and-administration/contents.md`：Data Guard Concepts and Administration（F31838-07）。Data Guard 物理/逻辑备库的概念和管理。
- `data-guard-broker/contents.md`：Data Guard Broker（F31839-04）。用 Broker 配置和切换 Data Guard。

## 备份与恢复

- `backup-and-recovery-users-guide/contents.md`：Database Backup and Recovery User's Guide（F31836-11）。RMAN 备份、恢复和闪回的用法。
- `backup-and-recovery-reference/contents.md`：Database Backup and Recovery Reference（F31837-09）。RMAN 命令和恢复目录视图。

## 安全

- `security-guide/contents.md`：Database Security Guide（F31285-18）。用户、权限、审计和数据加密等安全配置。

## SQL 与开发

- `sql-language-reference/contents.md`：SQL Language Reference（F31301-19）。SQL 语句、函数、数据类型和语法图。在线文档 F31301-19，本地 PDF 为 F31301-17。
- `sql-language-quick-reference/contents.md`：SQL Language Quick Reference（F31302-11）。SQL 语法的简表。
- `pl-sql-language-reference/contents.md`：Database PL/SQL Language Reference（F31827-07）。PL/SQL 语言、游标、包和触发器语法。
- `pl-sql-packages-and-types-reference/contents.md`：Database PL/SQL Packages and Types Reference（F31492-25）。DBMS_、UTL_ 等内置包和类型。在线文档 F31492-25，本地 PDF 为 F31492-21。
- `sqlplus-users-guide-and-reference/contents.md`：SQL*Plus User's Guide and Reference（F31846-03）。SQL*Plus 命令、脚本和报表。
