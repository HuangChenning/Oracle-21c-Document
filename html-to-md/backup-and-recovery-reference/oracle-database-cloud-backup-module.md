Oracle Database Cloud Backup Module enables you to back up Oracle databases to Oracle Cloud Infrastructure Object Storage by using the Oracle Database Backup Cloud Service.

Oracle Database Backup Cloud Service is the storage solution for backups and restores of Oracle databases with Oracle Cloud. Oracle Database Cloud Backup Module is an SBT interface that is integrated with Recovery Manager (RMAN). Database backups are created using RMAN and the Oracle Database Cloud Backup Module sends these backups, over the network, to Oracle Database Backup Cloud Service for offsite storage.
