## Model Functions

Model functions can be used only in the `model_clause` of the `SELECT` statement. The model functions are:

- [CV](CV.md)
- [ITERATION\_NUMBER](ITERATION_NUMBER.md)
- [PRESENTNNV](PRESENTNNV.md)
- [PRESENTV](PRESENTV.md)
- [PREVIOUS](PREVIOUS.md)
