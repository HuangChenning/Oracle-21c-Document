## 7.312 USER\_ANALYTIC\_VIEW\_CLC\_MEAS

`USER_ANALYTIC_VIEW_CLC_MEAS` is identical to `USER_ANALYTIC_VIEW_CALC_MEAS`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
