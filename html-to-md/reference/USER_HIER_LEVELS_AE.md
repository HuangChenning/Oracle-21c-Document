## 7.497 USER\_HIER\_LEVELS\_AE

`USER_HIER_LEVELS_AE` describes the levels of the hierarchies (across all editions) owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_HIER_LEVELS_AE`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
