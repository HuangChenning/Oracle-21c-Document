## 7.603 USER\_PART\_COL\_STATISTICS

`USER_PART_COL_STATISTICS` displays column statistics and histogram information for the table partitions owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_PART_COL_STATISTICS`.
