## 6.124 DBA\_JAVA\_COMPILER\_OPTIONS

`DBA_JAVA_COMPILER_OPTIONS` displays information about all native compiler options in the database. Its columns are the same as those in `ALL_JAVA_COMPILER_OPTIONS`.
