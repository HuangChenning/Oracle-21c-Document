## 7.406 USER\_COL\_PRIVS\_RECD

`USER_COL_PRIVS_RECD` describes the column object grants for which the current user is the grantee. Its columns (except for `GRANTEE`) are the same as those in `ALL_COL_PRIVS_RECD`.
