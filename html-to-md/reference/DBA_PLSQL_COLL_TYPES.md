## 6.243 DBA\_PLSQL\_COLL\_TYPES

`DBA_PLSQL_COLL_TYPES` describes all named PL/SQL collection types in the database. Its columns (except for `CHAR_USED`) are the same as those in `ALL_PLSQL_COLL_TYPES`.
