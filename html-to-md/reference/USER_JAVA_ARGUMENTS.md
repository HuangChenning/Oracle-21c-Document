## 7.528 USER\_JAVA\_ARGUMENTS

`USER_JAVA_ARGUMENTS` displays argument information about the stored Java classes owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_JAVA_ARGUMENTS`.
