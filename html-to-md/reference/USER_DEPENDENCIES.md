## 7.445 USER\_DEPENDENCIES

`USER_DEPENDENCIES` describes dependencies between procedures, packages, functions, package bodies, and triggers owned by the current user, including dependencies on views created without any database links. Its columns are the same as those in `ALL_DEPENDENCIES`.
