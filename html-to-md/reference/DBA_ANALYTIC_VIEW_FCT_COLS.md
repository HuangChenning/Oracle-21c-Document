## 5.84 DBA\_ANALYTIC\_VIEW\_FCT\_COLS

`DBA_ANALYTIC_VIEW_FCT_COLS` is identical to `DBA_ANALYTIC_VIEW_FACT_COLS`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
