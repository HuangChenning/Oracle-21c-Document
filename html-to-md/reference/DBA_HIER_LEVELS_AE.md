## 5.368 DBA\_HIER\_LEVELS\_AE

`DBA_HIER_LEVELS_AE` describes the levels of all hierarchies (across all editions) in the database. Its columns are the same as those in `ALL_HIER_LEVELS_AE`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
