## 7.560 USER\_MINING\_MODEL\_ATTRIBUTES

`USER_MINING_MODEL_ATTRIBUTES` describes the machine learning model attributes owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_MINING_MODEL_ATTRIBUTES`.
