## 5.85 DBA\_ANALYTIC\_VIEW\_FCT\_COLS\_AE

`DBA_ANALYTIC_VIEW_FCT_COLS_AE` describes the fact columns of all analytic views (across all editions) in the database. Its columns are the same as those in `ALL_ANALYTIC_VIEW_FCT_COLS_AE`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
