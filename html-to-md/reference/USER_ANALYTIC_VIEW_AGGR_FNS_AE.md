## 7.300 USER\_ANALYTIC\_VIEW\_AGGR\_FNS\_AE

`USER_ANALYTIC_VIEW_AGGR_FNS_AE` describes the aggregation functions of the analytic views (across all editions) owned by the current user. Its columns (except for `OWNER` and `ORIGIN_CON_ID`) are the same as those in `ALL_ANALYTIC_VIEW_AGGR_FNS_AE`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
