## 5.76 DBA\_ANALYTIC\_VIEW\_DIM\_ATTRS

`DBA_ANALYTIC_VIEW_DIM_ATTRS` describes the attributes of all attribute dimensions in the database. Its columns are the same as those in `ALL_ANALYTIC_VIEW_DIM_ATTRS`.

Note:

This view is available starting with Oracle Database 21c.
