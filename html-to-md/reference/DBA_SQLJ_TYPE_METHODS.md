## 6.373 DBA\_SQLJ\_TYPE\_METHODS

`DBA_SQLJ_TYPE_METHODS` describes the methods of all SQLJ object types in the database. Its columns are the same as those in `ALL_SQLJ_TYPE_METHODS`.
