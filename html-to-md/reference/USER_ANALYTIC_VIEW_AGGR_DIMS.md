## 7.298 USER\_ANALYTIC\_VIEW\_AGGR\_DIMS

`USER_ANALYTIC_VIEW_AGGR_DIMS` describes the aggregation function dimensions of the analytic views owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ANALYTIC_VIEW_AGGR_DIMS`.

Note:

This view is available starting with Oracle Database 21c.
