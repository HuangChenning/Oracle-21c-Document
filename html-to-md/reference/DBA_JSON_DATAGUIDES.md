## 6.141 DBA\_JSON\_DATAGUIDES

`DBA_JSON_DATAGUIDES` provides information on all JavaScript Object Notation (JSON) columns in the database that have data guide enabled. Its columns are the same as those in `ALL_JSON_DATAGUIDES`.
