## 7.624 USER\_QUEUE\_EVENT\_STREAMS

`USER_QUEUE_EVENT_STREAMS` describes the Transactional Event Queue (TEQ) event streams owned by the current user. Its columns are the same as those in `ALL_QUEUE_EVENT_STREAMS`.

Note:

This view is available starting with Oracle Database 21c.
