## 7.318 USER\_ANALYTIC\_VIEW\_DIM\_ATTRS

`USER_ANALYTIC_VIEW_DIM_ATTRS` describes the attributes of the attribute dimensions in the analytic views owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ANALYTIC_VIEW_DIM_ATTRS`.

Note:

This view is available starting with Oracle Database 21c.
