## 5.207 DBA\_BASE\_TABLE\_MVIEWS

`DBA_BASE_TABLE_MVIEWS` describes all materialized views using materialized view logs in the database. Its columns are the same as those in `ALL_BASE_TABLE_MVIEWS`.
