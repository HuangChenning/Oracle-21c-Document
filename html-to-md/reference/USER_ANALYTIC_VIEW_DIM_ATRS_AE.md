## 7.317 USER\_ANALYTIC\_VIEW\_DIM\_ATRS\_AE

`USER_ANALYTIC_VIEW_DIM_ATRS_AE` describes the attributes of the attribute dimensions in the analytic views (across all editions) owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ANALYTIC_VIEW_DIM_ATRS_AE`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
