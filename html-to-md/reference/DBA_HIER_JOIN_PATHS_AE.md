## 5.364 DBA\_HIER\_JOIN\_PATHS\_AE

`DBA_HIER_JOIN_PATHS_AE` describes the join paths for all hierarchies (across all editions) in the database. Its columns are the same as those in `ALL_HIER_JOIN_PATHS_AE`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
