## 7.723 USER\_TAB\_STAT\_PREFS

`USER_TAB_STAT_PREFS` displays information about statistics preferences for the tables owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_TAB_STAT_PREFS`.
