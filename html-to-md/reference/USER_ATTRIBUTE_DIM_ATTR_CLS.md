## 7.354 USER\_ATTRIBUTE\_DIM\_ATTR\_CLS

`USER_ATTRIBUTE_DIM_ATTR_CLS` is identical to `USER_ATTRIBUTE_DIM_ATTR_CLASS`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
