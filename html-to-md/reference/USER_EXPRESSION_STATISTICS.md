## 7.466 USER\_EXPRESSION\_STATISTICS

`USER_EXPRESSION_STATISTICS` provides expression usage tracking statistics for tables owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_EXPRESSION_STATISTICS`.
