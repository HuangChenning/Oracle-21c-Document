## 7.483 USER\_HEAT\_MAP\_SEGMENT

`USER_HEAT_MAP_SEGMENT` displays the latest segment access time for all segments owned by the user. Its columns (except for `OWNER`) are the same as those in `ALL_HEAT_MAP_SEGMENT`.
