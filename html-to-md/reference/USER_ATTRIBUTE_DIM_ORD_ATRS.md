## 7.373 USER\_ATTRIBUTE\_DIM\_ORD\_ATRS

`USER_ATTRIBUTE_DIM_ORD_ATRS` is identical to `USER_ATTRIBUTE_DIM_ORDER_ATTRS`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
