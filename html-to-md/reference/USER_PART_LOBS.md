## 7.607 USER\_PART\_LOBS

`USER_PART_LOBS` displays table-level information about the partitioned LOBs owned by the current user, including default attributes for LOB data partitions. Its columns (except for `TABLE_OWNER`) are the same as those in `ALL_PART_LOBS`.
