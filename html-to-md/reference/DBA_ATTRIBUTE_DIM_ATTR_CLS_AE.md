## 5.141 DBA\_ATTRIBUTE\_DIM\_ATTR\_CLS\_AE

`DBA_ATTRIBUTE_DIM_ATTR_CLS_AE` describes the attribute classifications of all attribute dimensions (across all editions) in the database. Its columns are the same as those in `ALL_ATTRIBUTE_DIM_ATTR_CLS_AE`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
