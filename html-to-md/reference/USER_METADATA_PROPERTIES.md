## 7.557 USER\_METADATA\_PROPERTIES

`USER_METADATA_PROPERTIES` describes OLAP metadata properties in the current user's schema. Its columns (except for `OWNER`) are the same as those in `ALL_METADATA_PROPERTIES`.
