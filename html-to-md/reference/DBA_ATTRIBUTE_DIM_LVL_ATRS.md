## 5.154 DBA\_ATTRIBUTE\_DIM\_LVL\_ATRS

`DBA_ATTRIBUTE_DIM_LVL_ATRS` is identical to `DBA_ATTRIBUTE_DIM_LEVEL_ATTRS`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
