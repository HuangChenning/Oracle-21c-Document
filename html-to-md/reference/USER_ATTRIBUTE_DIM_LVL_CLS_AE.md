## 7.372 USER\_ATTRIBUTE\_DIM\_LVL\_CLS\_AE

`USER_ATTRIBUTE_DIM_LVL_CLS_AE` describes the level classifications of the attribute dimensions (across all editions) owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ATTRIBUTE_DIM_LVL_CLS_AE`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
