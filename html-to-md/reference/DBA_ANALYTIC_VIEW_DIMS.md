## 5.81 DBA\_ANALYTIC\_VIEW\_DIMS

`DBA_ANALYTIC_VIEW_DIMS` is identical to `DBA_ANALYTIC_VIEW_DIMENSIONS`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
