## 6.261 DBA\_QUEUE\_TABLES

`DBA_QUEUE_TABLES` contains information about the owner instance for a queue table.

A queue table can contain multiple queues. In this case, each queue in a queue table has the same owner instance as the queue table. Its columns are the same as those in `ALL_QUEUE_TABLES`.
