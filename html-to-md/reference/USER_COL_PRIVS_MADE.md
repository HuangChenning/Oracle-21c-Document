## 7.405 USER\_COL\_PRIVS\_MADE

`USER_COL_PRIVS_MADE` describes the column object grants for which the current user is the object owner. Its columns (except for `OWNER`) are the same as those in `ALL_COL_PRIVS_MADE`.
