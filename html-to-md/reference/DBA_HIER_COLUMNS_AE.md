## 5.358 DBA\_HIER\_COLUMNS\_AE

`DBA_HIER_COLUMNS_AE` describes the columns of all hierarchies (across all editions) in the database. Its columns are the same as those in `ALL_HIER_COLUMNS_AE`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
