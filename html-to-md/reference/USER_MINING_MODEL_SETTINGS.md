## 7.562 USER\_MINING\_MODEL\_SETTINGS

`USER_MINING_MODEL_SETTINGS` describes the machine learning model settings owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_MINING_MODEL_SETTINGS`.
