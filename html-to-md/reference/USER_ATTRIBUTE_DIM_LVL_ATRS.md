## 7.368 USER\_ATTRIBUTE\_DIM\_LVL\_ATRS

`USER_ATTRIBUTE_DIM_LVL_ATRS` is identical to `USER_ATTRIBUTE_DIM_LEVEL_ATTRS`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
