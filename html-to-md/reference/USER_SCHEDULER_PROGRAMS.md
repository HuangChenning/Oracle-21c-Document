## 7.662 USER\_SCHEDULER\_PROGRAMS

`USER_SCHEDULER_PROGRAMS` displays information about the Scheduler programs owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_SCHEDULER_PROGRAMS`.
