## 7.687 USER\_SQLTUNE\_PLANS

`USER_SQLTUNE_PLANS` displays information about the execution plans generated for the SQL statements owned by the current user during a SQL tuning session. Its columns are the same as those in `DBA_SQLTUNE_PLANS`.
