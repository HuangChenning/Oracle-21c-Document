## 5.60 DBA\_ANALYTIC\_VIEW\_AGR\_DIMS\_AE

`DBA_ANALYTIC_VIEW_AGR_DIMS_AE` describes the aggregation function dimensions of all analytic views (across all editions) in the database. Its columns are the same as those in `ALL_ANALYTIC_VIEW_AGR_DIMS_AE`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
