## 5.267 DBA\_CUBE\_NAMED\_BUILD\_SPECS

`DBA_CUBE_NAMED_BUILD_SPECS` describes the OLAP cube named build specifications in the database. Its columns are the same as those in `ALL_CUBE_NAMED_BUILD_SPECS`.
