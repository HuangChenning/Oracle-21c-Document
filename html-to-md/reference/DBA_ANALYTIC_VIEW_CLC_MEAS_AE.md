## 5.71 DBA\_ANALYTIC\_VIEW\_CLC\_MEAS\_AE

`DBA_ANALYTIC_VIEW_CLC_MEAS_AE` describes the calculated measures in all analytic views (across all editions) in the database. Its columns are the same as those in `ALL_ANALYTIC_VIEW_CLC_MEAS_AE`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
