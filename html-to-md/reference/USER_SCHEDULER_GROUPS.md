## 7.652 USER\_SCHEDULER\_GROUPS

`USER_SCHEDULER_GROUPS` displays information about the Scheduler object groups owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_SCHEDULER_GROUPS`.
