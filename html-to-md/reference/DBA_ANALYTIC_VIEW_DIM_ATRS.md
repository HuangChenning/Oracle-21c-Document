## 5.74 DBA\_ANALYTIC\_VIEW\_DIM\_ATRS

`DBA_ANALYTIC_VIEW_DIM_ATRS` is identical to `DBA_ANALYTIC_VIEW_DIM_ATTRS`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
