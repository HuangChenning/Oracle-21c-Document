## 7.606 USER\_PART\_KEY\_COLUMNS

`USER_PART_KEY_COLUMNS` describes the partitioning key columns for the partitioned objects owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_PART_KEY_COLUMNS`.
