## 5.96 DBA\_ANALYTIC\_VIEW\_LVL\_CLS

`DBA_ANALYTIC_VIEW_LVL_CLS` is identical to `DBA_ANALYTIC_VIEW_LEVEL_CLASS`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
