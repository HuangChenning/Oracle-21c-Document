## 7.493 USER\_HIER\_JOIN\_PATHS\_AE

`USER_HIER_JOIN_PATHS_AE` describes the join paths for the hierarchies (across all editions) owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_HIER_JOIN_PATHS_AE`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
