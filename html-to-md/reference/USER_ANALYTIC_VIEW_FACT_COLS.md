## 7.325 USER\_ANALYTIC\_VIEW\_FACT\_COLS

`USER_ANALYTIC_VIEW_FACT_COLS` describes the fact columns of the analytic views owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ANALYTIC_VIEW_FACT_COLS`.

Note:

This view is available starting with Oracle Database 21c.
