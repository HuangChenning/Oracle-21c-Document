## 7.535 USER\_JAVA\_LAYOUTS

`USER_JAVA_LAYOUTS` displays class layout information about the stored Java classes owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_JAVA_LAYOUTS`.
