## 7.616 USER\_POLICIES

`USER_POLICIES` describes all Oracle Virtual Private Database (VPD) security policies associated with objects owned by the current user. Its columns (except for `OBJECT_OWNER`) are the same as those in `ALL_POLICIES`.
