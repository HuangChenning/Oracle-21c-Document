## 7.389 USER\_BASE\_TABLE\_MVIEWS

`USER_BASE_TABLE_MVIEWS` describes the materialized views using materialized view logs owned by the current user. Its columns are the same as those in `ALL_BASE_TABLE_MVIEWS`.
