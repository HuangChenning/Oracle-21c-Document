## 7.287 USER\_ADVISOR\_SQLPLANS

`USER_ADVISOR_SQLPLANS` displays the different SQL execution plans owned by the current user generated as part of an advisor analysis. Its columns are the same as those in `DBA_ADVISOR_SQLPLANS`.
