## 7.307 USER\_ANALYTIC\_VIEW\_BAS\_MEAS\_AE

`USER_ANALYTIC_VIEW_BAS_MEAS_AE` describes the base measures in the analytic views (across all editions) owned by the current user. Its columns (except for `OWNER`) are the same as those in `ALL_ANALYTIC_VIEW_BAS_MEAS_AE`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
