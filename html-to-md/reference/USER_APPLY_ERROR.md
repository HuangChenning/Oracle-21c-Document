## 7.348 USER\_APPLY\_ERROR

`USER_APPLY_ERROR` displays information about the error transactions generated by apply processes visible to the current user. Its columns (except for `SOURCE_ROOT_NAME`) are the same as those in `ALL_APPLY_ERROR`.
