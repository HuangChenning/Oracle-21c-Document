## 7.664 USER\_SCHEDULER\_RESOURCES

`USER_SCHEDULER_RESOURCES` displays all scheduler resource objects in the database from the schema of the current user. Its columns (except for `OWNER`) are the same as those in `ALL_SCHEDULER_RESOURCES`.
