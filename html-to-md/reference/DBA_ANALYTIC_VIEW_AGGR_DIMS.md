## 5.56 DBA\_ANALYTIC\_VIEW\_AGGR\_DIMS

`DBA_ANALYTIC_VIEW_AGGR_DIMS` describes the aggregation function dimensions of all analytic views in the database. Its columns are the same as those in `ALL_ANALYTIC_VIEW_AGGR_DIMS`.

Note:

This view is available starting with Oracle Database 21c.
