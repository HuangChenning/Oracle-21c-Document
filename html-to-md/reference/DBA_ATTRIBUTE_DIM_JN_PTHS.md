## 5.146 DBA\_ATTRIBUTE\_DIM\_JN\_PTHS

`DBA_ATTRIBUTE_DIM_JN_PTHS` is identical to `DBA_ATTRIBUTE_DIM_JOIN_PATHS`.

Note:

This view is available starting with Oracle Database 21c, Release Update 21.5.
