## 7.573 USER\_MVIEW\_KEYS

`USER_MVIEW_KEYS` describes the columns or expressions in the `SELECT` list upon which materialized views in the current user's schema are based. Its columns are the same as those in `ALL_MVIEW_KEYS`.
