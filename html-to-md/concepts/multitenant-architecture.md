## Part I Multitenant Architecture

The **multitenant architecture** enables an Oracle database to function as a multitenant container database (CDB).

This part contains the following chapters:

- [CDBs and PDBs](CDBs-and-PDBs.md)
- [Application Containers](app-containers.md)

- [CDBs and PDBs](CDBs-and-PDBs.md)  
	The **multitenant architecture** enables an Oracle database to function as a multitenant container database (CDB).
- [Application Containers](app-containers.md)  
	Within a CDB, you can create a container for application data and metadata that can be shared by PDBs.
